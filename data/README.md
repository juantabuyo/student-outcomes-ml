# Data for this project

`synthetic_students.csv` is an entirely fictitious 180-row fixture generated by
`synthetic_data.py`. Its purpose is to exercise the schema, models and plots. Its
scores are not evidence about real students. It is not sampled from the original
CSV and does not reproduce individual student records.

The university submission used `rendimiento_estudiantes.csv`, a semicolon-separated
4,424-row, 37-column dataset with translated Spanish field names and categories.
The available submission does not establish the original source, licence or exact
translation mapping, so those records are deliberately excluded. The fields are
listed in `../data_schema.csv`; that is a schema, not a copy of the data.

To reproduce the full experiment, obtain an authorised copy of the **same course
CSV** from the course provider, confirm its redistribution terms and translation
mapping, and pass its local path to `main.py --data`. No automatic download is
provided. A similarly named public dataset must not be silently treated as
identical. Check the SHA-256 in `../results/corrected_full/run_metadata.json` if
using the exact original file. You do not need to put the file in this directory.

The binary fields use the source values `si`/`no`; the outcome field `objetivo`
uses `abandono`, `matriculado` and `graduado`. The loader validates the contract:
it requires every column of `../data_schema.csv` and rejects any other column
(for example an export index or an identifier), because each extra column would
otherwise become a predictor in both tasks without a leakage review. Remove such
columns first.
Plots translate the outcome display labels while retaining source feature names.
This makes it possible to trace a figure back to a column without altering data.

The exact observation time of administrative fields, including `deudor` and
`matricula_al_dia`, remains unverified. Do not assume all regression predictors
would be available at a real first-semester prediction date.
